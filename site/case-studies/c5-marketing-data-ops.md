# C5 · Marketing Data Ops

## Facts
- Operated Facebook campaigns across **20+ countries**, ~3,000 BHD managed budget, ≈800,000 monthly reach (Apr 2025 onward — visible as sustained Ads/Analytics activity).
- TikTok video campaigns launched; TikTok API integration in progress with the self-hosted omnichannel stack (see C1).
- **Data engineering for marketing**:
  - Akilibot campaign data prep: master stats → per-campaign conversation rates (Jul 2026).
  - Contact-list normalization: OpenRefine + custom GREL/JS for international phone numbers, country-code mapping (966/KSA etc.), date-format reconciliation across campaigns (DD/MM vs MM/DD).
  - "Move off Google Sheets" migration: Sheets → Grist/NocoDB/Postgres evaluation and import tooling (Jul–Sep 2026).
  - Country-level shahadah/conversion dashboards (Sep 2025–Aug 2026 reporting), animated country-globe visualization prototype.
