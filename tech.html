The toolkit

Tech Toolkit

For the curious and the technical reviewer: the actual tools behind the work, explained in plain English. The rest of the site keeps this terminology out of your way.

Infrastructure — where things run

TermPlain English
Self-hostedYour software runs on servers you control, not on a vendor's.
Open-sourceThe code is free for anyone to inspect, modify, and run.
VPSA rented server on the internet — your own machine in a data center.
DockerPacks software so it runs identically on any machine.
TraefikRoutes visitors to the right app and handles secure connections automatically.
TailscaleA private network so servers talk to each other without being on the public internet.
KubernetesRuns and scales containerized apps across many servers.

Data — where information lives

TermPlain English
PostgreSQLA powerful, widely used database.
NocoDBA spreadsheet-style interface on top of a real database.
Twenty (CRM)An open-source customer-relationship system — a smart address book plus a sales pipeline.
Row-level securityA rule so each person sees only the rows that belong to them.
OpenRefineA tool for cleaning messy data (duplicates, bad formats).
GrafanaTurns live data into dashboards and charts.

Automation & AI

TermPlain English
n8nConnects your apps so work flows automatically between them.
ChatwootOne shared inbox for WhatsApp, Messenger, TikTok and more.
Botpress / DifyTools for building AI chatbots and automatic replies.
LLM"Large language model" — the engine that writes answers (e.g. DeepSeek, Qwen).
RAG"Retrieval-augmented generation" — the AI looks up your own documents before answering, so it doesn't invent facts.
WhisperXTurns long audio into text.
TTS / ASRText-to-speech / speech-to-text.

Connections & APIs

TermPlain English
APIA doorway that lets two programs talk to each other.
WhatsApp / Messenger / TikTok Business APIOfficial doorways to send and receive platform messages from your own system.
EazypayA local payment gateway.
WebhookA signal that fires when something happens ("a new message arrived").
MarkdownPlain-text formatting that both people and machines can read.
GitVersion history for code — every change is kept, nothing is lost.

How the on-site AI works

  • This site publishes the same content twice: as pages for people, and as plain files (llms.txt, .md twins, JSON) that machines can read.
  • When you type a question, the assistant finds the most relevant pieces of that content.
  • If a language model is connected, it writes a short answer using only those pieces — with links to the sources. If not, it shows the most relevant page directly.
  • Either way, it never invents numbers that aren't already on the site.
